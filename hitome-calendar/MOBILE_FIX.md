# ひとめ予定帳 スマホ表示修正（2026-10-01）

320px幅のChromeブラウザー画面で、主要入力・保存・ダイアログの表示範囲を確認しました。クローゼットは390px幅でも確認。iPhone/Android実機、Safariのソフトウェアキーボード、実機カメラ撮影は今回の検証に含みません。
