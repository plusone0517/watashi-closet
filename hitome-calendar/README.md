# ひとめ予定帳 — HITOME PLANNER

本業・副業・家族・自分の予定を色分けし、月のカレンダーと一覧で一括管理するWebアプリです。

## 機能
- 予定の追加・編集・削除と、削除直後の取り消し
- 4種類のカレンダー、月送り、今日へ移動、文字検索、種類で絞り込み
- 開始・終了日時、終日・複数日の予定、場所、メモ
- 時間を指定した予定同士の重なりを表示（終日の予定は対象外）
- IndexedDBへの端末内保存と、JSONバックアップの保存・取込み
- サンプル体験を実際の予定と分離
- スマートフォンでは日付を選ぶと、その日の一覧へ移動

## 保存と制限
予定は使っている端末・ブラウザのIndexedDBに保存します。予定データの外部送信はありません。URL配布はアプリの共有であり、利用者の予定の共有ではありません。ブラウザのデータ消去・端末変更・プライベートモードに備え、バックアップを保管してください。

Google・Apple等のカレンダーとの自動同期、共同編集、通知、繰り返し予定、祝日表示は含みません。日時はタイムゾーン変換を行わない端末の現地時刻として扱います。端末のタイムゾーンを変えても登録した時計表示を維持します。

上限5,000件。バックアップは12MBまで。同じIDは取込み元で更新、それ以外は追加し、既存予定を削除しません。日付と項目の型を検証してから、ひとつのトランザクションで取り込みます。

## 検証（2026-10-01）
日付の月末・年末・閏日、終日の終了境界、時間の重なり、不正入力のテストに合格。ブラウザで登録、再読込み後の保持、編集、重なり表示、終了時刻の検証、バックアップ取込み、月・一覧表示を確認。幅390pxの表示を確認しました。物理スマートフォンでの検証は行っていません。

WebMCPは対応ブラウザでread_scheduleとstart_event_creationを登録します。後者はフォームを開くだけで保存しません。テスト環境ではmodelContextが利用できず、WebMCP実行検証は未実施です。通常の画面操作には影響しません。

## 再ビルド
Node.js 22.13以降、pnpmを使用します。
1. source.zipを展開し、pnpm install --frozen-lockfile
2. pnpm build
3. release/index.htmlをHTTPSの静的ホスティングで配布

配布HTMLにJavaScript・CSS・faviconを含めています。外部APIキーとサーバーは不要です。pnpm devは生成済みreleaseを表示します。ソース変更後はpnpm buildで更新してください。
