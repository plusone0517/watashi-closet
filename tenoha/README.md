# てのは / TENOHA

Japanese-language, smartphone-friendly 3D sign-motion studio. This is an **unreviewed motion demonstration**, not a translation or professionally validated teaching tool.

## Functions

- Eight authored expressions: ありがとう / よろしくお願いします / おはよう / こんにちは / すみません / わかる / おめでとう / 元気.
- Character-ngram multinomial Naive Bayes classifier trained locally on small explicit phrase examples. It selects related supported expressions, rejects low-coverage input, and requires the user to choose a candidate.
- Jointed 3D hands, fingers and arms, head movement; play, pause, seek, restart, loop, 0.5 / 0.75 / 1 speed, front / side / closer views.
- Three.js WebGL rendering and depth-buffered Canvas 2D software projection of the same meshes when WebGL is unavailable.
- No server, authentication, analytics, camera, microphone or transmitted input. Text is ephemeral in page memory. External reference links are normal outgoing links.

## Limits

Motion and facial expression are simplified and have not been reviewed by a Deaf signer or sign-language specialist. Not suitable as accurate instruction or interpretation. No arbitrary-sentence translation, generative signing, signing recognition, speech recognition, correctness scoring or conversational avatar. The AI component is phrase classification; the animation is authored, not generated by AI.

## Build

Node.js 22+, pnpm 11.25.0. Install dependencies with `pnpm install`, then run `node scripts/build-portable.mjs release/index.html`. The output is a single self-contained HTML document. Deploy the generated `index.html` on any static web host; no runtime service configuration is required. Do not deploy local QA pages.

Source modules: `lib/signs.ts` (model and content), `lib/motion.ts` (authored motion), `components/avatar.tsx` (geometry and WebGL), `lib/software-renderer.ts` (CPU rendering), `app/page.tsx` (UI).

Optional WebMCP: feature-detected `read_sign_player` and `select_sign_phrase` use the same state handlers. This environment does not expose WebMCP tools, so its registration cannot be verified here.

## Verification

TypeScript type check; canonical/alias/unsupported classifier checks; 808 sampled motion states checked for finite values, normalized rotation and reachable wrist positions; browser QA of play, pause, candidate selection, speed, camera, explanatory dialog, and 375px content width. Software rendering verified in the test browser (WebGL is disabled there). Professional sign accuracy remains unverified.
