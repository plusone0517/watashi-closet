# わたしのクローゼット — CLOSET

手持ちの服を写真で管理し、場面・天気・気温に合わせて組合せを作るWebアプリです。写真中心の画面と、スマホでも使える大きめの操作ボタンを備えています。

## 初期版の機能

- 服・小物の写真、名前、カテゴリ、色、厚み・季節、着たい場面、メモを登録・編集・削除
- 名前・色・メモの検索、カテゴリで絞り込み
- 普段着・お仕事・お出かけと、手入力した天気・気温に応じて登録済みの服を組み合わせる
- 洗濯中・お休み中の服を候補から除外
- 服をタップして入れ替え、別の組合せを表示
- 日付と名前を付けてコーデを保存、保存時の写真・情報を見返す
- 写真込みのJSONバックアップを保存・復元
- 9点のサンプルで体験（サンプル画像は生成画像。ユーザーのデータと分離）

## 保存と制限

写真とデータは同じ端末・同じブラウザーのIndexedDBに保存します。サーバーには送信しません。端末をまたぐ自動同期・アカウント・家族共有はありません。ブラウザーのデータ削除、プライベートモード終了、保存容量の制約などで失われる可能性があるため、バックアップを用意しています。復元は確認後に現在の全データを置き換えます。

天気と気温は手入力です。組合せは登録した場面・季節・色・雨向け情報によるルールベースの提案です。写真から服の形・素材を自動解析する機能、生成AIによる自由なスタイリング、天気の自動取得、骨格・パーソナルカラー診断、占い、買い物機能は初期版に含みません。

保存したコーデは保存時のスナップショットです。元の服を編集・削除しても、保存したコーデ内の情報は変わりません。サンプルのコーデは実データとして保存しません。

画像は20MBまで。端末内で長辺960pxのJPEGに圧縮します。バックアップ取込みは80MBまで、服・コーデそれぞれ1,000件まで検証します。

## ソースと再ビルド

配布ファイルは index.html、ソースは source.zip に収録しています。React・TypeScript・Tailwind CSS・shadcn/uiを使用。

1. source.zipを展開
2. Node.js 22.13以降とpnpm 11.25を用意
3. `pnpm install --frozen-lockfile`
4. `node scripts/build-portable.mjs release/index.html`
5. 生成したHTMLをHTTPSの静的ホスティングに公開

外部APIキー、サーバー処理、課金設定は不要です。開発元の写真や実ユーザーのデータはリポジトリに含めません。
