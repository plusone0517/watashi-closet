# しるし旅 — 御朱印・御城印の旅手帳

AIアプリ開発プロジェクト第6作。訪問先・日付・御朱印／御城印の写真を、個人のアルバムと地図で振り返るWebアプリです。

## できること

- 神社・お寺・お城の訪問記録を登録・編集・削除
- 印の写真、訪問日、都道府県、住所、思い出のメモ、お気に入り
- 写真中心のアルバム、キーワード検索、種類・都道府県・お気に入りの絞込み、日付順
- 国土地理院の地図に訪問記録を表示。ピンから記録を開く
- 地図をタップ、または中心位置を選んで訪問位置を指定
- 写真を含むJSONバックアップの書出し・確認後の復元
- 架空のサンプル3件（個人データとは分離）

## 保存とプライバシー

記録と写真は同じ端末・同じブラウザーのIndexedDBに保存します。アカウントや端末間の自動同期はありません。URLを配布しても、他の利用者に記録を公開しません。同じブラウザープロファイルを共用する人は同じデータにアクセスできます。

ブラウザーのデータ削除、プライベートモードの終了、端末故障等に備え、バックアップを保存してください。復元前に件数と置換の確認を表示します。複数タブによる古いデータの上書きはrevisionの照合で防ぎ、再読込みを案内します。保存に失敗した場合は入力内容を保持してエラーを表示します。

写真は最大20MB、端末内で長辺1,600pxのJPEGに変換します。記録は最大1,000件、バックアップ読込みは120MBまでです。印刷用の高解像度保管庫ではないため、原本写真は別途保持してください。

## 地図と印について

地図はLeaflet 1.9.4と地理院タイルを使用します。表示時にタイル画像を国土地理院から読み込み、範囲を示すタイル座標と通常のHTTP情報が送られます。写真・名前・住所・メモは送信しません。地図にはインターネット接続が必要です。出典を画面内に表示しています。

出典・仕様：
- https://maps.gsi.go.jp/development/ichiran.html
- https://maps.gsi.go.jp/development/siyou.html
- https://leafletjs.com/examples/quick-start/

住所の自動検索・現在地の自動取得はありません。都道府県を選んだ段階では県庁所在地付近の概略位置を置き、施設の正確な位置とは表示を区別します。地図上で指定するとその座標を保存します。

このアプリは個人の訪問と撮影した印の記録用です。寺社・城が発行する正式な印や公式電子印を提供しません。サンプルの施設名・記録は架空、カバーは生成したイメージ写真です。

## 再ビルド

React・TypeScript・Tailwind CSS・shadcn/ui。配布版は外部スクリプトを読み込まない単一HTMLです（地図画像は除く）。

1. `source.zip`を展開
2. Node.js 22.13以降とpnpm 11.25を用意
3. `pnpm install --frozen-lockfile`
4. `node scripts/build-portable.mjs release/index.html`
5. 生成したindex.htmlをHTTPSで静的配信

利用者データ、試験用ファイル、秘密情報はソースに含みません。WebMCP対応ブラウザー向けに集計の読取りと画面検索のツールも用意しています。未対応ブラウザーでは通常の画面操作を利用できます。

## 検証

型検査・公開HTMLの生成、登録と再読込み、写真読込み、地図ピンから詳細表示、地図位置指定、入力・バックアップの検証、絞込みと不正データの拒否を確認しています。
